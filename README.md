# UNO for My GF 💖🃏

Game kartu **UNO Online** yang dibuat dengan penuh cinta oleh **Hugo** untuk dimainkan bersama **Lulu** (dan teman-teman). Bisa langsung dimainkan dari HP, tablet, maupun laptop masing-masing secara online tanpa perlu install aplikasi apapun!

---

## ✨ Fitur-Fitur Spesial

1. **🌐 Multiplayer Online Nyata (Serverless WebRTC P2P)**:
   - Terhubung langsung antar-perangkat menggunakan WebRTC (PeerJS) & BroadcastChannel.
   - Tanpa perlu backend server berbayar — host room dan langsung main!

2. **💌 Salin Link Undangan Sekali Klik**:
   - Tombol **"📋 Salin Link Undangan"** di Lobby & Game.
   - Cukup kirim link (misal: `https://.../?room=ABCD`) ke WhatsApp ayang; saat link dibuka, kode room otomatis terisi!

3. **🐱 Avatar Karakter & Emoji Menggemaskan**:
   - Pilihan avatar emoji hewan lucu (`🐱 Kucing`, `🐰 Kelinci`, `🐻 Beruang`, `🐼 Panda`, `🌸 Bunga`, `💖 Hati`, `👑 Queen`, `🦊 Rubah`, `🐥 Anak Ayam`).
   - Pilihan warna tema badge avatar sesuai selera.

4. **✨ Quick Floating Reactions (Emotes)**:
   - Tombol reaksi instan: ❤️ (Love), 🥺 (Pout), 😡 (Mad), 🥳 (Hore), 😂 (Ketawa), 😭 (Nangis), 🃏 (UNO).
   - Emoji akan melayang naik di layar semua pemain dengan animasi dan efek suara lucu!

5. **🎨 Theme Switcher (Dark Neon vs Pastel Love Mode)**:
   - **Dark Neon**: Tampilan elegan modern dengan aksen warna kartu yang menyala.
   - **Pastel Love**: Tampilan manis bertema pink, cream, dan rose gold yang feminin dan lembut.

6. **🎉 Hujan Confetti Hati & Pesan Kemenangan Spesial**:
   - Hujan partikel confetti berbentuk hati ❤️ dan bintang ✨ saat ada pemain yang berhasil menghabiskan kartu.
   - Pesan kemenangan romantis spesial jika Lulu yang memenangkan permainan!

7. **⚡ Mekanik Gameplay Lengkap & Halus**:
   - **Aturan Resmi UNO**: Skip, Reverse, Draw 2 (+2), Wild, dan Wild Draw 4 (+4).
   - **Draw-and-Play**: Jika menarik kartu dari deck dan kartunya cocok, muncul opsi langsung memainkan kartu tersebut atau menyimpannya.
   - **House Rules 7-0**: Kartu 7 bisa menukar semua kartu tangan dengan pemain lain; kartu 0 memutar seluruh kartu pemain.
   - **Jump-In Rule**: Bisa langsung merebut giliran jika memiliki kartu yang persis sama.
   - **Tumpukan Tarik (+2 / +4 Stacking)**: Bisa menumpuk kartu draw agar lawan berikutnya menarik lebih banyak kartu.
   - **Tangkap Lupa UNO**: Tangkap pemain yang tersisa 1 kartu tapi lupa menyerukan "UNO!".
   - **Timer Giliran (30 Detik)**: Mencegah pemain AFK atau ketiduran saat giliran tiba.
   - **Main Cepat (Lawan Bot)**: Mode single-player offline melawan bot AI yang pintar.

## 🚀 Cara Menjalankan & Bermain

### 1. Jalankan di Komputer Lokal
Cukup buka file `index.html` dengan klik dua kali atau drag & drop ke browser kesukaanmu (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox).

### 2. Main Online Berdua (Deploy Gratis)
Kamu bisa meng-online-kan game ini secara gratis dalam 1 menit:
- **GitHub Pages**:
  1. Masuk ke repository ini di GitHub.
  2. Masuk ke tab **Settings** > **Pages**.
  3. Pada opsi **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
  4. Link game kamu akan siap dalam beberapa detik (contoh: `https://hugo.github.io/uno-for-my-gf/`).
- **Vercel / Netlify**:
  - Drag & drop folder project ini ke dashboard Vercel atau Netlify.

---

## 🎮 Cara Bermain

1. **Sebagai Pembuat Room (Host)**:
   - Buka game, masukkan nama kamu (misal: Hugo), pilih avatar lucu, lalu klik **"Buat Room Baru"**.
   - Klik **"Salin Link Undangan"** dan kirimkan link ke WhatsApp pacar kamu.
   - Setelah dia bergabung ke lobby, klik **"Mulai Permainan"**!

2. **Sebagai Pemain yang Bergabung**:
   - Buka link undangan yang dikirimkan.
   - Masukkan nama kamu (misal: Lulu), pilih avatar, lalu klik **"Gabung Room"**.

3. **Lawan Bot**:
   - Jika ingin latihan sendiri, klik **"⚡ Main Cepat (Lawan Bot)"** di halaman utama.
